# Beam Designer

Beam Designer is a Python desktop app for analyzing simply supported beams and cantilevers. It shows reactions and shear, moment, and deflection diagrams; checks bending stress and deflection; and can save designs as JSON or export results to CSV and a PDF calculation sheet. A passing check is not complete structural design approval.

## Requirements

- Python 3 with Tkinter
- No additional Python packages

## Start

```sh
python3 beam_designer.py
```
